# Introduction vocabulary sheet

Plain and technical definitions live in the glossary. This sheet is the Bell-lab reminder. A qubit has a quantum state described with amplitudes. Measurement returns one classical result.

## Software words

Use the Home Depot table only for these words. The analogy stops before superposition and entanglement.

| Programming concept | Home Depot analogy |
| --- | --- |
| Qiskit ecosystem | The entire Home Depot |
| Package or library | A department or toolbox |
| Module | A specific aisle |
| Class | The design or type of tool |
| Object or instance | The actual tool selected |
| Method | An action the tool can perform |
| Argument | A setting, measurement, or instruction |
| Variable | A labeled container holding something |
| Circuit | The construction blueprint |
| Backend | The job site where the work runs |
| Transpilation | Adapting the blueprint to local building codes and available equipment |
| Sampler | The inspection team collecting outcomes |
| Shots | The number of repeated inspections |
